## Fonts

The game ships no font files. It asks Windows for these by name and falls back to standard Windows faces when they
are missing:

- **Ink Free** and **Segoe Print** (handwriting), **Palatino Linotype** / **Book Antiqua** / **Georgia** (body), and
  **Old English Text MT** (titles), all Microsoft fonts already on the player's PC.

## Artwork, music and sound

- **Map, portraits, paper texture and journal:** drawn in code at run time.
- **Music and sound effects:** synthesised in code at startup (a Karplus–Strong plucked string, simple bells and
  filtered noise). No samples or recordings are used.
- **The HH logo, app icon and installer artwork:** generated by `tools/make_icon.py` and
  `tools/make_installer_art.py` using **TeX Gyre Chorus** and **TeX Gyre Pagella** (GUST Font License, a free
  licence derived from the LaTeX Project Public License, https://www.gust.org.pl/projects/e-foundry/tex-gyre). Only
  the rendered images are shipped, not the fonts.

## Inspirations

Classic country-house mysteries and the deduction board game *Cluedo* (*Clue*) inspired the setting and the
process of elimination. No names, artwork, text or rules are taken from them; every case, character and line of
dialogue is generated.

## Build tools (not shipped)

- **Inno Setup 6** (https://jrsoftware.org/isinfo.php) builds the installer.
